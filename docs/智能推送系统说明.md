# 智能题目推送系统说明

## 概述

基于学习记忆规律的智能题目推送系统，已全面替代原有的随机推送逻辑。

## 核心特性

### 1. 动态间隔算法

根据以下因素动态计算复习间隔：
- **连续正确次数**：连续答对越多，间隔越长
- **历史错误次数**：错误越多，复习越频繁
- **题目难度**：难度越高，复习间隔越短

#### 间隔计算示例

| 场景 | 原间隔 | 新间隔 | 说明 |
|------|--------|--------|------|
| 首次答错简单题 | 1天 | 0.75天 | 难度系数1.5x |
| 首次答错中等题 | 1天 | 1天 | 难度系数1.0x |
| 首次答错困难题 | 1天 | 1.5天 | 难度系数0.7x |
| 高频错题(≥5次) | 12小时 | 6小时 | 加速复习 |
| 连续正确3次 | 4天 | 7天 | 已掌握，延长间隔 |

### 2. 多维度推送优先级

#### 评分权重
- **紧急度 40%**：距离下次复习时间
- **薄弱度 30%**：历史错误频率+正确率
- **重要性 15%**：用户标记+掌握状态
- **新鲜度 15%**：避免短时间内重复推送

#### 优先级示例
```
紧急度(过期3天): 100分 × 0.40 = 40分
薄弱度(错误8次,正确率25%): 90分 × 0.30 = 27分
重要性(标记重要+未掌握): 80分 × 0.15 = 12分
新鲜度(3天没做): 80分 × 0.15 = 12分
-------------------------------------------
总分: 91分 (优先推送)
```

### 3. 三种推送模式

#### A. 复习模式（默认）
混合策略：
- 70% 到期错题（按优先级排序）
- 20% 薄弱章节新题
- 10% 历史答对题目（随机巩固）

#### B. 挑战模式
- 根据用户平均答题难度智能匹配
- 难度自适应：用户水平±0.5
- 题目不足时自动扩展难度范围

#### C. 专项突破模式
- 针对特定章节集中推送
- 优先推送该章节错题
- 同一知识点变式题连续出现

- 多人对战（`/game/create-room`）

- 换对手（`/game/change-opponent/<room_code>`）

## 降级策略

所有智能推送功能都有降级机制：
- 算法异常 → 回退到传统推荐
- 题目不足 → 扩展难度/章节范围
- 数据缺失 → 使用默认值

## 稳定性保障

1. **向后兼容**：原有逻辑保留，平滑过渡
2. **异常处理**：所有入口都有 try-except 保护
3. **日志记录**：失败时记录详细错误日志
4. **降级策略**：智能推送失败自动降级

## 性能优化

1. **批量查询**：减少数据库查询次数
2. **缓存友好**：可配合Redis缓存用户统计数据
3. **分页加载**：避免一次性加载大量题目

## 配置说明

### 动态间隔系数（可调整）

```python
# 难度系数（题目难度对间隔的影响）
difficulty_coefficients = {
    1: 1.5,  # 简单题间隔更长
    2: 1.0,  # 中等题标准间隔
    3: 0.7,  # 困难题间隔缩短
    4: 0.5   # 极难题密集复习
}

# 掌握度系数（连续正确次数对间隔的影响）
mastery_coefficients = {
    0: 0.5,  # 刚答错，缩短间隔
    1: 0.8,  # 正确1次
    2: 1.0,  # 正确2次，标准间隔
    3: 1.2,  # 正确3次，延长间隔
    4: 1.5   # 正确4次+，大幅延长
}

# 基础间隔（天）
base_intervals = {
    0: 0.5,  # 首次错误
    1: 1,    # 连续正确1次
    2: 3,    # 连续正确2次
    3: 7,    # 连续正确3次
    4: 14,   # 连续正确4次
    5: 30,   # 连续正确5次
    6: 60    # 连续正确6次+
}
```

## 常见问题

**Q: 为什么推送的题目感觉变难了？**
A: 系统会根据你的水平匹配题目，这是正常现象。如果觉得太难，可以选择指定难度的房间。

**Q: 复习题目变少了？**
A: 系统去重了最近做过的题目，避免无效重复。复习质量比数量更重要。

**Q: 可以关闭智能推送吗？**
A: 目前默认启用。如需关闭，可在路由中注释掉智能推送的导入语句。
